This folder contains the code used in **Rapid detection of cultivated truffle fungi (Tuber spp.) from truffles, root tips, and soil using loop-mediated isothermal amplification**. The **Unique Regions** folder contains target sequences and the **Primers** folder contains both the unverified and published primer sets for each species. Please reach out to Alassane Sow (a.sow@ufl.edu) with any questions!
