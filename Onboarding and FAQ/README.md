# HiperGator Tips and Tricks
## Submitting jobs
When submitting a job, it may take a while to run becuase all of the resources have been pertitioned for someone else.  
To check what resources are being used, simply run
```console
squeue -A plantpath
```
The department has an additional account, ```plantpath```
